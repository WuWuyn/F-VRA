# PyShare data layers

- `final/vf_benchmark_finalized.jsonl`: finalized CVE-to-function benchmark.
- `final/severity_sources.jsonl`: per-CVE CVSS, CWE, EPSS, and source evidence.
- `interim/`: normalized CVE scope, candidate functions, and annotation work.
- `processed/`: generated inputs consumed by experiments and evaluation tools.
- `_scans/`: raw and normalized outputs from external SCA scanners.

`processed/cve_to_vf_evaluation.jsonl` is generated by:

```powershell
pyshare eval prepare-data
```

Do not edit that generated file by hand. Update one of the two finalized source
files and rebuild it.
